# PMQ-002.6 — Initial Failure

## Frozen proposition

> If the represented protected consequence has formed, the system MUST retain a recoverable durable record of that formation even if the subsequent consequence-receipt creation path fails.

## Initial execution

GitHub Actions run: `32162230269`

Integrated result:

**1 failed / 48 passed**

## Classification

**FAIL — CONSEQUENCE FORMED WITHOUT RECOVERABLE OUTCOME EVIDENCE**

## Observed failure

The protected consequence returned `CONSEQUENCE_FORMED` before the receipt-producing wrapper attempted to create the `ConsequenceOutcomeReceipt`.

The challenge injected a failure into that subsequent receipt-creation step. The exception was correctly surfaced, but there was no durable consequence-outcome store from which the fact of represented consequence formation could be recovered.

The test therefore found a real crash/evidence gap: represented formation and represented evidence creation were separate in-memory steps with no durable formation record between them.

## Scope

This is a reference-MVP evidence-durability failure. It does not establish anything about external payment settlement, production audit storage, database HA or distributed transactions.

The failure is preserved before remediation.
