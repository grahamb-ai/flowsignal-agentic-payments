# PMQ-002.5 — Authority-State Rollback Result

## Frozen proposition

> Once authority state version N has been superseded by a later committed version, the represented authority-state mechanism MUST NOT permit the current state to move backwards to N such that an execution permit bound to N can regain standing and form the represented protected consequence.

## Initial result

Classification:

**FAIL — SUPERSEDED AUTHORITY STATE RESURRECTED**

The initial authority store used a directly assignable module-level integer. After state N was superseded by N+1, the challenge restored that reachable value to N and the store reported N as current again.

The failure was preserved in `PMQ-002.5_INITIAL_FAILURE.md` before remediation.

## Remediation

The directly assignable authority-state integer was replaced by a private monotonic state holder. The represented public mutation surface remains forward-only through `advance_authority_state_version()`.

The frozen adversarial test was not weakened: it still attempts to assign the former `_AUTHORITY_STATE_VERSION` name back to the superseded value N and then checks whether the actual authority store moved backwards. That assignment can no longer alter the authoritative state used by standing validation.

## Demonstrated scope

The represented reference-harness authority state is no longer controlled by the directly assignable module-level version integer that falsified the initial proposition. Its supported mutation operation is monotonic/forward-only, and the frozen rollback attempt does not restore old standing.

## Residual limitations / NOT DEMONSTRATED

This does **not** establish:

- production database or storage anti-rollback guarantees;
- resistance to arbitrary memory/process compromise;
- malicious administrator resistance;
- immutable or append-only authority-state persistence;
- rollback protection across process restart;
- distributed state monotonicity or consensus;
- external IAM/KMS/HSM state monotonicity;
- protection against storage snapshot restoration.

Those remain separate proof obligations.

## Strongest safe conclusion

Within the represented in-process authority-store surface exercised by PMQ-002.5, the rollback path that initially resurrected a superseded authority-state version has been removed, and the unchanged rollback challenge no longer restores standing to the old permit.
