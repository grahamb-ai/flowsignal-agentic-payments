# VPC-001.2 — Parallel Admissibility Drift

## Frozen third-party scenario

Two independently valid actions can be individually admissible while competing over a shared real-world condition. The first consequence can materially change the authoritative state relevant to the second before the second binds.

## Frozen comparative propositions

### VPC-001.2A — Response to a supplied authoritative collision/change signal

If Action A forms a consequence and a materially newer authoritative state or explicit revalidation condition is established before Action B reaches its final admission/execution boundary, Action B MUST NOT proceed on the earlier unchanged authority basis.

### VPC-001.2B — Autonomous discovery of an unrepresented global collision

If no shared authoritative state, correlation signal, dependency relation, or revalidation trigger is supplied to the runtime, does the public implementation independently discover that two otherwise-valid actions conflict globally?

## Classification rules

- **PASS** — executable public evidence establishes the proposition within a stated bounded scope.
- **PARTIAL** — relevant mechanism exists but only part of the proposition is executable.
- **ND** — not demonstrated by the inspected public implementation.
- **FAIL** — the implementation claims/exposes the proposition but the frozen executable challenge contradicts it.

The comparison MUST NOT treat ND as FAIL where the capability is outside the implementation's declared public claim boundary.
