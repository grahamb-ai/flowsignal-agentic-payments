# CAT-001.5 — Governed Route Closure

**Qualification date:** 20 August 2026  
**Target:** `Kamanaka5502/bind-time-authority-proof` public bounded demonstrator  
**Frozen target commit:** `d71d743e23098fb58454d8d412cb4a988681d2c1`  
**Classification:** PARTIAL — documented `/commit` route is locally gated; broader route closure is NOT DEMONSTRATED

## Frozen proposition

> Within the represented public demonstrator boundary, a credible consequence-producing path MUST NOT bypass the authority enforcement path being claimed.

## Frozen evidence requirement

Identify the public consequence-producing surface and attempt the most credible reachable bypass available through the published demonstrator.

A PASS may establish closure only for tested governed/public routes. Universal external route closure is `ND` unless independently demonstrated.

## Public claims relevant to the proposition

The frozen README states that if authority cannot be proven at the consequence boundary, execution does not proceed. The threat model refers to an admission gate before execution, corridor isolation and fail-closed refusal.

The same README explicitly declares the repository a bounded demonstrator and withholds the production corridor implementation, protected runtime law, production ledger and commercial deployment architecture.

## Public consequence-like surface inspected

`boundary_server.py` exposes the principal documented public commit path found in the frozen repository.

For `POST /commit`, the handler:

- validates `X-Corridor` against the allowed corridor set;
- enforces the expected parent chain tip;
- enters a process-local lock;
- calls `DeterministicBoundary.evaluate(prior_tip)`;
- returns before represented chain mutation when the decision is not `EXECUTE`;
- advances `RECEIPT_INDEX`, `CHAIN_TIP`, appends a receipt and persists the ledger only on the `EXECUTE` branch.

This establishes real route-local ordering in the published handler: the documented route does not advance its represented receipt chain before its inline decision gate.

## Credible bypass assessment

The frozen public repository does not expose a second documented API or separately isolated executor that reaches the same represented consequence while omitting the authority evaluation.

It also does not expose an execution capability, permit or token that can be presented independently to a separate consequence-forming component. The evaluator and the represented receipt-chain mutation are co-located inside the same handler/module.

Accordingly, the strongest public bypass proposition that can be assessed without modifying the target is whether an alternate published consequence-producing route exists that reaches the same represented mutation without the gate. None was identified in the frozen public surface inspected.

However, absence of a second documented route is not equivalent to an executed failed bypass attempt. CAT-001.5 requires evidence that a credible consequence-producing path was actually challenged. The frozen public demonstrator does not expose a distinct reachable consequence surface against which such a bypass can be independently exercised while preserving the repository's declared public-use boundary.

## Result

**PARTIAL — documented `/commit` route is locally gated; broader route closure is NOT DEMONSTRATED.**

The target earns credit for actual route-local enforcement in the published `/commit` handler. This is stronger than a purely narrative claim.

A full PASS is not earned because CAT-001.5 has not demonstrated a failed credible bypass against a separately observable consequence surface, and the public repository does not establish that every route to a represented or external consequence is closed.

This is not a FAIL because no consequence-producing bypass has been demonstrated.

## Strongest safe conclusion

> On the frozen public demonstrator, the documented `/commit` handler places its represented receipt-chain mutation after corridor, parent and inline decision checks, and returns before that mutation on a non-`EXECUTE` result. No separately exposed public consequence route was identified that can be independently invoked to test bypass of that gate. Governed-route gating is therefore demonstrated, while route closure / non-bypassability beyond that route remains NOT DEMONSTRATED.

## Residual proof obligations

- expose a separately observable represented protected consequence;
- execute at least one credible direct-consequence or alternate-route bypass attempt;
- demonstrate that such an attempt cannot form the consequence without the authority path;
- distinguish route-local inline gating from execution-capability isolation;
- universal external route closure and production enforcement remain outside the declared public demonstrator boundary.

## What this result does not prove

This result does not establish universal non-bypassability, production process/IAM isolation, key custody, distributed route closure, or external physical consequence protection. It is limited to the frozen public demonstrator and the documented `/commit` route inspected.
