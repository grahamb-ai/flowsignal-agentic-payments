## Frozen proposition

> The public proof claim SHOULD be reproducible by an independent party from the published object and its documented run instructions, without private intervention required to obtain the claimed public result.

- install pytest and optional requirements;
- run `pytest -q`;
- run `python ci_replay_check.py`.

This is meaningful reproducibility material and is credited.

## Reproduction limitations identified on the frozen revision

The frozen repository contains import/API inconsistencies relevant to a clean independent run. For example, inspected root-level adversarial/test material imports `advanced_execution_field` as a root module while the inspected implementation is located under `bind_time_authority_fabric/advanced_execution_field.py`.

The inspected package implementation imports `sign` and `verify` from `bind_time_authority_fabric.standing_token`, while the public proof surface has undergone signing-interface changes and separate signature helpers also exist. These inconsistencies require care before treating the repository as a single clean executable proof object.

For the exact frozen commit, the available GitHub workflow-run lookup did not return a pull-request-triggered workflow run that could be used here as independent execution evidence. Absence from that lookup is not treated as proof that no Actions run ever existed; it simply means CAT-001 cannot rely on a returned run for this frozen revision.

CAT-001 has not modified or republished the target implementation to repair those issues, consistent with the target's restricted-use boundary.

## Classification

**PARTIAL — public object and CI intent are available, but the frozen revision does not provide a clean independently evidenced reproduction of the claimed proof surface.**

This is not a FAIL because the repository contains runnable-oriented source, tests and explicit CI commands, and CAT-001 is not asserting that no subset can execute.

It is not a PASS because the full frozen public proof claim has not been independently reproduced from the exact revision without resolving repository/import/interface inconsistencies or relying on private intervention.

## Strongest safe conclusion

> The target publishes an immutable public object and a clear intended CI invocation, which materially supports reproducibility. On the exact CAT-001 frozen revision, however, the inspected repository contains execution-layout/interface inconsistencies and CAT-001 has no returned exact-revision workflow run establishing a clean independent reproduction of the complete claimed proof surface. Independent reproduction is therefore PARTIAL.

## Scope limitation

This result does not state that the target owner's private or production implementation is unreproducible, nor that no historical CI run exists. It classifies only the independently available evidence for the exact frozen public revision.
