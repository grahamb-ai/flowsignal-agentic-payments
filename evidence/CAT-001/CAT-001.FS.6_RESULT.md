# CAT-001.FS.6 — Independent Execution Capability

**Target:** FlowSignal Agentic Payments reference-MVP  
**Frozen target commit:** `4c5092c8df704a58327c4a5e5c6ae9fc81755ef2`  
**Classification:** PASS — bounded represented component/module isolation; production trust-boundary isolation NOT DEMONSTRATED

## Frozen proposition

Within the represented boundary, code/components outside the authority decision/issuance mechanism MUST NOT be able to manufacture or independently obtain whatever execution capability is sufficient to form the protected represented consequence.

## Evidence

EC-002 froze and executed this proposition directly against the represented execution component. The first run genuinely failed all four checks: the executor exposed a callable permit issuer, signing key, signing primitive and embedded reference signing secret. That failure was preserved.

Remediation moved permit issuance/signing into `app.engines.permit_authority`. The represented `app.engines.protected_consequence` consumes/verifies permits but no longer contains or exports the issuer, permit key, signing primitive or embedded permit secret. The unchanged four EC-002 assertions passed on rerun, and the no-bind attack remained semantically preserved after the interface separation.

## Classification

**PASS — bounded represented component/module isolation.**

The CAT proposition is satisfied for the represented execution component actually exercised: the executor cannot independently mint the consequence-authorising capability through the tested public reference surface.

## Historical failure lineage

The current PASS explicitly preserves the initial EC-002 failure. The failure is material evidence that the capability boundary was previously absent and that the current result was earned by strengthening rather than assumed from architecture.

## Strongest safe conclusion

> On the frozen FlowSignal reference-MVP, the represented execution component no longer possesses the tested independent capability to mint/sign a consequence-authorising execution permit. This is a bounded component/module PASS.

## Residual limitation

`permit_authority.py` and `protected_consequence.py` remain in one Python reference codebase/runtime trust domain. Separate OS/process/network identities, IAM enforcement, KMS/HSM custody, privileged-operator separation and production secret isolation remain NOT DEMONSTRATED.
